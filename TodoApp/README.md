# To-Do App

This app allows you to create, edit and delete tasks, give them priorities and due dates and includes several options to sort and filter.

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) (version 10.0 or higher)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)

## Getting Started

### Clone the repository 

- git clone https://github.com/kirsnif/TodoApp
- cd TodoApp

### Start the database

- docker compose up -d

To stop it:

- docker compose down

### Restore dependencies 

- dotnet restore

### Run the app

- dotnet run
